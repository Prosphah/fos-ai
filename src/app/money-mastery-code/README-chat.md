### 90-Day Money-Back Guarantee

I would, however, define reasonable refund conditions so the guarantee doesn't become an abuse vector.

You don't need:

> "Only 17 spots left!"

because this is a recorded course.

Instead, use **value-based urgency** around the evolving FOSAI product.

For example:

> **The course is recorded. Your access isn't going anywhere.**
>
> But FOSAI is an evolving product, and early Money Mastery Code students get access to the version available during this phase of the program.

You can then legitimately introduce future pricing:

> **Founding access pricing**
>
> ₦23,000 today.
>
> As FOSAI develops and more capabilities are added, the price of the complete Money Mastery system may increase.

You could also introduce occasional bonuses:

* Live financial Q&A
* New FOSAI features
* New investment analysis lessons
* Portfolio review session
* New templates

But don't promise things you haven't committed to delivering.
